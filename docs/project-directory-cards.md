# 项目卡片与项目首页

应用启动默认进入项目页。全局工作台暂时隐藏，旧总览入口转向项目页；跨项目任务链接、项目内概览及独立窗口位置恢复仍保留。

项目页默认卡片，可切换到原列表并记住选择。标题操作、搜索、分组、收藏、归档、状态摘要和排序共用同一页面布局与目录状态，切换展示方式仅替换项目内容区。列表保留 Git 检查与批量操作。

## 任务统计

任务摘要读取独立任务工作区中关联到当前项目的任务。待办、已到开始时间、已完成、紧急、逾期与阻塞按叶任务统计，避免父子任务重复计数。高优先级未完成任务计为紧急，逾期按任务时区判断，依赖阻塞可从父任务传递到子任务。子任务均已完成的未完成父任务单列为待收尾。点击摘要会打开同一规则筛选的关联任务列表。

卡片计数和任务目标筛选共用成员选择函数，点击跳转后可清除筛选。未启用和读取失败显示未知，不显示为零。

## 运行数据

`readProjectDirectorySummaries({ projectIds })` 是批量只读 IPC。任务读取一次分组，运行摘要复用各项目缓存；每环境仅返回最近部署，平台确认的生产指向单独保留。不同项目与不同来源的读取失败互不影响。

页面进入、任务及服务更新、恢复可见和每 60 秒检查时读取本地摘要。隐藏后暂停。打开目录或点击“刷新摘要”不会调用云平台、启动 SSH 检查或发起域名巡检；需要更新线上结果时进入对应运行页面使用既有刷新或检查入口。

生产环境优先，其他环境展开查看。部署结果、域名健康、同步时间分别显示；云数据超过 5 分钟、域名结果超过 10 分钟标注过期，服务器沿用既有周期。读取失败保留已有运行数据并显示错误。

## 验证

- `node scripts/run-tests.mjs`：任务口径、目标筛选、批量来源隔离、生产回滚与最新失败分离、导航兼容。
- `node scripts/workspace-smoke.mjs --project-cards --exit`：实际 Electron、SQLite 与 preload 的隔离验收，覆盖视图记忆、任务与日志跳转、快速筛选、隐藏暂停、缓存过期、局部错误及明暗主题和窄窗口。
- `node scripts/workspace-smoke.mjs --projects-perf --interactions --exit`：原列表与 Git 操作入口回归。

验收只使用临时项目与模拟只读平台响应，不修改用户数据或远端发布状态。

## 项目负责人视角

目录首页新增全部项目、需要处理、待收尾、信息待完善四个可点击摘要。统计以当前搜索与分组范围内的项目去重，同一项目可同时属于多个类别，不把紧急、逾期和阻塞的数量直接相加。默认按关注优先级排列，仍可恢复原分组顺序；两种视图展示同一份筛选和排序后的项目结果。列表的 Git 批量操作仅针对当前结果中选中的项目，已被筛选隐藏的选择不会进入批量操作。

卡片默认统一呈现任务交付、开发和线上运行。开发复用最近仓库扫描的工作区改动、未推送仓库数和分支，并明确标注缓存，不据此推断交付完成度。生产部署与域名可用性分开展示；完整的多服务、多环境、日志入口在“运行明细”中展开。

缺少数据和已知故障分开处理：未启用任务、未确认生产指向、同步错误和检查过期归入信息待完善；新鲜的生产部署失败、最新环境部署失败、域名异常及停止的服务器归入需要处理。历史部署失败不会持续污染项目状态。总体标签“暂无待处理项”只表达已有记录中的结果，不推断业务健康或项目完成率。

## 公共页面布局

`ProjectDirectoryLayout` 管理标题操作、公共筛选与摘要、结果展示、对话框四个层次。卡片与列表不会改变公共区域的组件、位置、间距和主题样式；切换入口和“刷新摘要”各只有一份。搜索、分组、项目关注类别和排序也共用同一份结果集。

列表的本地 Git 检查与 Fetch／推送批量操作属于结果区。“刷新摘要”在两种视图中均重读本地摘要，手动检查 Git 状态保留为列表专用入口。每次切换保留现有筛选及列表选择，批量动作排除被筛选隐藏的项目。

隔离 Electron 验收会逐一对比切换前后的公共控件节点、边界位置和计算样式，并验证结果成员及排序相同，覆盖明暗主题及 1440／760／560 像素窗口。
