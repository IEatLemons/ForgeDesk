# 本地任务工作区

「任务」与「概览」「项目」同级。任务支持多清单归属、两套分组、父子任务、前后置依赖、里程碑标记、富文本、附件及本地人员。

在任务详情的「关联项目」可选择多个项目。项目目录的「关联任务」列出该项目的任务，可新建任务或添加已有任务。每条任务在各关联项目中共享同一份内容与完成状态。归档项目保留关联，删除项目时移除该项目的关联并保留任务。

列表、看板和甘特图使用同一份任务数据。视图中的筛选、排序、分组和字段排列按页面保存。字段库支持单选、多选、人员、数值、日期和文本；复用同一个字段时，任务上的值也相同。

仪表盘提供 26 类本地组件，支持布局、尺寸、主题、全局与组件筛选、统计配置及任务明细跳转。NPS 使用选定数值字段的 0–10 分评分；计划时长使用起止日期，完成耗时使用创建和完成时间。没有有效数值的数据不参与平均值计算。

## 数据与升级

- 数据保存在现有 `forgedesk.db` 中的独立 `task_workspace_*` 表，通过项目 ID 保存任务与项目的关联。
- 第一次访问工作区时，先将数据库和旧任务 localStorage 原文备份至 `<userData>/task-workspace/backups/<批次>/`，备份成功后才事务性清理退休的任务、托管任务、目标、关键结果、里程碑和版本计划数据。
- 初始化标记与清理放在同一事务中；失败会回滚，备份失败不会执行清理。初始化成功后不再重复清理。
- 原 Codex 会话、仓库、项目和部署发布记录保留。新工作区从空数据开始，仅创建本地「我」身份。
- 附件复制到 `<userData>/task-workspace/attachments/`，原文件移动不会影响任务附件。图片预览支持 PNG、JPEG、GIF 和 WebP；其他附件通过本机默认应用打开。

升级前数据库备份中的 `forgedesk.db` 和 `legacy-local-storage.json` 可用于人工恢复旧版本数据；恢复数据库前应先退出应用，避免覆盖正在写入的数据库。

## 重复与提醒

重复任务在完成当前任务时生成下一条，保持原计划周期并跳过已经错过的周期。支持天、周、月、年、工作日和自定义间隔。月末、闰年与时区变化会保留周期基准。独立生成记录防止重开、重复提交、重启或删除下一条后重复生成。

个人提醒由应用主进程每 30 秒检查，并在系统休眠恢复后检查；应用需要保持运行。全天任务按其时区当天 09:00 提醒，具体时间任务按设置的时间提醒。应用重新启动后检查遗漏提醒，同一个任务日期与提前量组合只提醒一次。点击通知会打开相应任务。

## 开发与验证

- `node scripts/run-tests.mjs task-workspace workspace-navigation project-archive project-detail-view`：数据层、备份回滚、重复任务、提醒、路由和项目独立性测试。
- `node scripts/preview-task-workspace.mjs`：使用临时 SQLite 数据库启动本机界面预览，不访问正式用户目录。加入 `--empty` 可检查空白状态；`FORGEDESK_TASK_PREVIEW_PORT` 可指定端口。预览数据仅用于验证，不会作为应用初始数据。
- `tsc --noEmit` 与 `electron-vite build`：类型检查和桌面三部分编译。

预览提供实际任务服务的查询、命令和历史接口；原生附件选择、系统通知和窗口更新广播应使用 Electron 验证。
