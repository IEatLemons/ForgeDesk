# Git 提交树阅读

提交树默认显示全部本地可读取引用，按拓扑顺序排列。只有 `repository:commit-graph` 使用拓扑排序，普通提交列表和提交分析保持原排序；刷新只读本地数据，不自动 Fetch。

## 看图与调宽

图谱列默认至少 160px，按实际轨道自动增长。拖动图谱标题右侧边缘可以调整宽度，方向键以 10px 微调，双击或 Home 恢复自动。拖动期间 Esc 或窗口失焦可取消。宽度偏好独立保存在 `forgedesk:git-log-layout:v1`，不迁移业务数据；轨道所需空间大于手动宽度时优先保证完整显示。

轨道间距至少 24px，拖宽后最多扩展到 40px，所有行共享同一套横向坐标。自动宽度在当前仓库与筛选上下文中只增长，切换上下文或恢复自动时重新计算。图谱按真实行高绘制，引用换行不会让合并曲线提前结束。

表格顶部的横向滚动条与表格同步，不需要滚到历史末尾才能查看其他列。“图谱专注”隐藏次要列，完整信息仍可从展开的提交详情中查看；切换仓库后恢复普通模式。

## 看关系

圆点代表普通提交，菱形代表真实的多父合并，提交说明中写有 merge 不会被当作多父合并。悬停或键盘聚焦节点可查看父提交 Hash；点击节点打开关系弹层。

已显示的父提交可以定位并高亮，不自动展开文件。未显示的父提交以虚线和“范围外”提示区分，可清除筛选或按现有窗口加载更早历史；不虚构分支，也不无限加载。工作区节点指向真实 HEAD，不把内部占位 Hash 显示为提交。

## 验证

`node scripts/run-tests.mjs git-log-view git-graph` 检查布局、边界及几何；`node scripts/workspace-smoke.mjs --git-graph --exit` 使用临时真实 Git 历史验证双父、多父、时间异常、窗口外父提交、调宽与偏好恢复、专注模式、定位、筛选清除、Diff、工作区，以及明暗主题和窄窗口。验收期间不触发用户仓库的 Git 写操作或远端 Fetch。
